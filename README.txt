**Team:** Tech Mind  
**Team leader:** Tejashwi Mehta (12623021)  
**Team members:** Krish Kumar (12622357), Keshav Kumar (12621705)

## How to run
1. Extract `Tech_Mind_Florist_Project.zip`.
2. Open the extracted folder.
3. Double-click `index.html` or open it with Chrome/Edge.
4. Internet is needed for the Google font and remote flower images/video. The core builder works locally without a server.

## Project features
- Flower stem selector: Red Roses, White Lilies, Pink Carnations, Yellow Sunflowers.
- Quantity controls and live price calculation.
- Four wrapping options: Kraft Paper Rustic, Luxury Matte Black, Glass Vase, Woven Basket.
- Greeting card composer with occasion presets and character count.
- Delivery form with HTML validation (name, 10-digit mobile, address, date, 6-digit PIN).
- Unique demo order ID, order table, search/filter, and status progression.
- Feedback form with rating.
- Responsive mobile navigation and layout.
- Semantic HTML, accessibility labels, SEO metadata, multimedia video element, CSS Grid/Flexbox, transitions and JavaScript DOM operations.

## Syllabus mapping (Units 1–4)
### Unit 1 — HTML5 foundations
Document structure, hyperlinks/navigation, lists/sections, images with alt text, SVG-style decorative symbol, multimedia video, metadata/SEO.

### Unit 2 — Semantic HTML and forms
`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, accessible labels, input types, required/pattern/minlength validation, select/textarea, and a data table.

### Unit 3 — CSS
Selectors, colors, typography, box model, Flexbox, Grid, hover states, transitions, keyframe animation, and responsive media queries.

### Unit 4 — JavaScript
Variables/constants, strings/numbers/booleans, operators, conditions, functions, arrays, objects, `find`, `filter`, `reduce`, event listeners, event delegation, DOM manipulation, form validation, generated IDs, and status updates.

## Important project limitation
This is a **frontend academic demonstration**. Orders exist in JavaScript memory only and are cleared when the page is refreshed. It does not connect to a real florist, database, payment gateway, or delivery service.
